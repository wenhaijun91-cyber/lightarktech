ArcOS

A model-agnostic compound-AI engine

ArcOS is built on one principle: perception belongs to the language model, while control, persona, and memory belong in hard-coded logic. A five-stage pipeline (perception → strategy → assembly → generation → memory) keeps an AI consistently in character and gives it durable long-term memory — on any backbone (Gemma, Llama, Qwen). Swapping the model is a configuration change, not a rewrite.

In production today

Our first product — a 24/7 AI companion for everyday support and reflection — runs on ArcOS and is live on the web and on desktop (macOS, Windows, Linux), with a native iOS app in development. It runs on a dedicated NVIDIA H200 we own and operate.
